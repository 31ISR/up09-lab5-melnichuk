## Краткое описание

Приложение Django демонстрирует работу с данным фреймворком, показывает реализацию базовых функций для сайта. 

### В проекте реализованы:
- Работа с шаблонами
- Маршрутизация 
- Панель администратора
- Работа с базой данных, создание и редактирование данных

## Установка и запуск

Для установки необходимо скачать файлы из репозитория (желательно через SSH). Для запуска необходимо:
1. Через Bash перейти в папку lab1
2. Запустить сервер при помощи команды `python manage.py runserver`

_Если при выполнении команды появляется ошибка о том, что не найдены Django и Pillow, необходимо будет их установить._

3. Перейти по адресу `localhost:8000/`

## Использование

Ограничений по использованию приложения нет. Можно использовать все функции приложения, а именно:

- Регистрация пользователя и вход в систему
- Создание постов и сообществ
- Просмотр созданных постов и сообществ
- Переход по ссылкам в приложении

При необходимости захода в панель администратора можно использовать уже созданного пользователя с логином `admin` и паролем `melok` или создать своего пользователя через Bash.

```
python manage.py createsuperuser
```

Программа попросит написать логин и пароль для нового админа, с помощью которых впоследствии можно будет войти в систему и, в частности, в панель администратора, где будет можно:

- Управлять пользователями
- Создавать, редактировать и удалять посты и сообщества
